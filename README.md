# Echo

An AI-powered emergency detection system that combines acoustic patterns, motion sensing, and secure SOS alerts to protect users when they may be unable to call for help.

## 🚨 Overview

Echo uses on-device acoustic AI and motion sensors to detect patterns associated with potentially dangerous situations. When the combined Threat Score crosses a configured threshold, Echo provides a 10-second cancellation window before activating an SOS.

## ✨ Key Features

- On-device acoustic analysis
- YAMNet + temporal sequence classification
- Accelerometer and gyroscope verification
- Dynamic Threat Score
- 10-second SOS cancellation window
- Voice and button cancellation
- 2–5 emergency contacts
- Live location sharing
- Offline SOS support
- Secure incident evidence handling
- Automated emergency alerts

## 🛠️ Tech Stack

- Kotlin / Android
- TensorFlow Lite
- YAMNet
- GRU-based sequence classifier
- Firebase
- Twilio
